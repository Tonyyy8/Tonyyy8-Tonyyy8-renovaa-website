## Uploaded files

Images, fonts and media uploaded to the design are written once each under
`assets/` — 2 in this export — and the exported files refer to them there. A
reference a script puts together while the page runs (for example
`"/_blob/" + id`) is not rewritten and does not load from this folder.

A page in a subfolder may not show an upload that reaches it through a script, a data
file or an imported component, because those files link to `assets/` from a different folder.

## Viewing

To view a page, start a local web server in this folder (for example `python3 -m http.server`), then open a page through it. These are the project’s own files, so a page that relies on the editor may not run from a folder.

## Left out of this export

This export leaves out files the editor keeps for its own use. It also leaves out hidden files
(files whose names start with a dot), except the ones a page saves for itself.
